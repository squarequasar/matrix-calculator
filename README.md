# Калькулятор матриц

Лабораторная работа 3, вариант 25: создание матрицы из одномерного массива.
Библиотека также поддерживает создание, освобождение, сложение, умножение и вывод матриц.
Ошибки размеров и пустых указателей сообщаются через std::invalid_argument.
Результаты операций владеют памятью и должны освобождаться через free_matrix ровно один раз;
копирование структуры не копирует данные. Массив должен содержать rows * cols элементов.

Сборка и проверка: `cmake -S . -B build`, `cmake --build build`,
`ctest --test-dir build --output-on-failure`, `./build/matrix_calculator`.
Проверяются обычные и прямоугольные матрицы, нулевая инициализация,
неверные размеры, пустой указатель и независимость от исходного массива.
Пример: массив 1, 2, 3, 4 при размере 2x2 создаёт строки [1, 2] и [3, 4].
Документация: `doxygen Doxyfile`. Контейнер: `docker build -t matrix-calculator .`,
затем `docker run --rm matrix-calculator`.
